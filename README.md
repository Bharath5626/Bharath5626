Built with a hybrid AI architecture — Google Gemini handles feature-level analysis while a deterministic engine computes project-level metrics.

### 📄 [ResumeAI Analyzer](https://github.com/Bharath5626/ResumeAIAnalyzer) — NLP-Powered ATS Tool

🔗 **Live Demo:** [resume-ai-frontend-28cb.onrender.com](https://resume-ai-frontend-28cb.onrender.com/) &nbsp;|&nbsp; **Stack:** FastAPI · React.js · SQLite · Google Gemini API · spaCy · PyJWT · Tailwind CSS

### 🎤 [InterviewAI Coach](https://github.com/Bharath5626/interviewai-coach) — Mock Interview Platform
> *AI-driven interview practice with real-time speech and emotion analysis*

Conducts **AI-driven mock interviews** with live webcam recording (WebRTC). Delivers detailed performance reports with progress tracking.
